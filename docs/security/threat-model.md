# Workflow threat model
Untrusted workflow data can only reference registered handlers; no code evaluation. Trusted host owns permissions, action versions, retry declarations and approval identity. Local checkpoint root and its ancestors must be trusted; no authenticated storage or hostile local writer protection. Dashboard is read-only, loopback-only, rejects cross-origin and unexpected hosts, limits checkpoint reads and refuses symlinks at file open; CSP and text rendering reduce injection risk. Local users can inspect synthetic checkpoint outputs; do not store secrets. Cancellation is cooperative; uncertain work is never automatically replayed. Atomic replacement is not a guarantee against power loss or exactly-once effects. AI mock-only; attempt budget persisted, per-adapter call budget remains process-local. Browser acceptance and further security review pending.

# Governance
Use runGoverned with a trusted action registry, explicit permission grants and policy callback. All side-effecting actions require a scope-bound approval. Review or denial pauses before execution; resume with a matching record. Checkpoint records the decision and approver identifier. Dry run invokes no handlers. Approvals bind execution ID, graph, task, action version and dependency outputs. Trusted host must maintain action versions, authenticate operators and protect checkpoint files; this is not a multi-user security boundary. Raw execute/runDurable are trusted internal primitives, not untrusted API endpoints. No automatic retries for declared side effects. No exactly-once guarantee.

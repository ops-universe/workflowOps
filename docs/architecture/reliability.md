# Reliability
Trusted host policies map handler names to maxAttempts (1–10), timeoutMs (0 disables; up to 300000), and idempotent (default false). Retries require explicit trusted idempotency and only occur on settled failures; stable execution/task key is supplied. Timeout or cancellation signals cooperative abort and leaves running checkpoint uncertain: no retries or later tasks; operator reconciliation required. A handler ignoring signals can continue after the engine returns; not a sandbox or hard kill. Cancellation between tasks leaves pending work resumable. Policy fingerprint prevents resume with changed policies. No exactly-once external side effects. Stale locks require operator inspection.

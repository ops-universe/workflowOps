# Local checkpoints
Use runDurable(def, registry, {directory}) to create a UUID execution. Resume using the same directory, executionId and resume:true. Definition fingerprint binds normalized graph structure, not handler implementation; use trusted versioned registry deployments. Local directory and checkpoint contents are trusted operator data, not authenticated. Exclusive lock prevents cooperative concurrent runs; stale lock after crash requires manual reconciliation. Running state is written before calling a handler; interrupted running tasks are never automatically replayed. Failed and blocked tasks remain terminal. JSON outputs and total checkpoint size bounded at 4 MiB; no secret outputs. File sync and atomic rename reduce torn writes, but power-loss durability is not guaranteed (directory fsync not implemented).
